# Approve Here 사용 가이드

Mac에서 Claude Code나 Codex를 쓰는데, 터미널 창을 찾아다니며 "허용할까요?"에 답하는 게 귀찮은 사람을 위한 안내입니다. 터미널을 열 일은 없습니다. 아래 화면은 모두 실제 앱에서 찍은 것입니다.

## 1. 내려받아 설치

[Release](https://github.com/SungHoonKim-Ski/approve-here/releases/latest)에서 **ApproveHere.dmg**를 내려받아 엽니다. 앱을 오른쪽 Applications 폴더로 끌어 넣습니다.

![DMG](guide/dmg.png)

## 2. 처음 열기

Applications에서 **Approve Here**를 엽니다. Apple 서명이 없는 앱이라 처음 한 번은 macOS가 막을 수 있습니다.

- "확인되지 않은 개발자" 안내가 뜨면: **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **"그래도 열기"**를 누릅니다.
- 또는 Finder에서 앱을 **우클릭 → 열기**.

앱은 창이 없습니다. 메뉴바(화면 위 오른쪽 아이콘 줄)에 받은편지함 모양 아이콘이 하나 생깁니다.

![메뉴바 아이콘 — 상태 아이콘 줄 맨 왼쪽의 받은편지함](guide/menubar.png)

## 3. 시작 안내에서 연결 켜기

처음 열면 화면 오른쪽 위에 시작 안내가 뜹니다. 여기서 세 가지를 켭니다.

![시작 안내](guide/onboarding.png)

1. **쓰는 CLI를 연결** — Claude Code, Codex 중 쓰는 것을 누릅니다. 앱이 각 CLI의 설정 파일(`~/.claude/settings.json`, `~/.codex/hooks.json`)에 훅 한 줄을 넣습니다. 다른 설정은 건드리지 않습니다.
2. **로그인 시 시작** — 켜 두면 Mac을 켤 때 같이 뜹니다.
3. **카드 시험해 보기** — 승인 카드가 어떻게 뜨는지 가짜 카드로 미리 봅니다.

> Codex는 새 훅을 처음 만나면 **신뢰 확인**을 요구합니다. 연결을 켠 뒤 처음 `codex`를 실행하면 "Hooks need review"가 뜨는데, **Trust all and continue**를 고르면 됩니다.

이 안내는 메뉴바 아이콘 → **시작 안내**로 언제든 다시 볼 수 있습니다.

## 4. 승인 카드

Claude Code나 Codex가 어떤 명령을 실행하기 전에 허락을 구하면, 화면 오른쪽 위에 카드가 뜹니다. 어느 앱을 보고 있어도 뜹니다.

![승인 카드](guide/card-permission.png)

- 머리: **어느 CLI · 어느 프로젝트**, 그 아래에 **그 세션에 마지막으로 시킨 일**
- 가운데: 실행하려는 명령과 agent가 붙인 설명
- **[허용]** 이번만 허용 · **[허용 + `npm test` 자동]** 이 명령 접두는 앞으로 묻지 않음 · **[거부]**
- `rm`, `sudo` 같은 되돌릴 수 없는 명령에는 "자동" 버튼이 나오지 않습니다.
- **✕**를 누르면 카드만 숨습니다. 요청은 메뉴에 남아 있어 거기서 답할 수 있습니다.

여러 세션이 동시에 물으면 카드가 쌓입니다.

![카드 두 장](guide/cards-stacked.png)

Claude Code는 카드가 뜬 동안 터미널에도 같은 질문을 띄웁니다 — 어느 쪽에서 답해도 됩니다. Codex는 카드에서 답해야 진행됩니다.

## 5. 질문 카드

Claude가 선택지를 주며 물을 때(`AskUserQuestion`)는 질문 카드가 뜨고 **소리**가 납니다.

![질문 카드](guide/card-question.png)

- 위쪽 상자: **왜 묻는지** — 질문 직전에 Claude가 한 설명
- 선택지는 설명과 함께 목록으로. 하나를 누르면 바로 답이 갑니다.
- 선택지에 없는 답은 **입력칸**에 적고 Enter.
- **✕**를 누르면 앱에서 답하지 않고 그 세션의 원래 다이얼로그로 넘어갑니다.

선택지가 없는 질문은 입력칸만 뜹니다.

![자유 입력 질문](guide/card-freetext.png)

질문이 여럿이면 각각 고른 뒤 **[답 보내기]**를 누릅니다.

![질문 두 개](guide/card-two-questions.png)

Claude는 카드에서 고른 답을 그대로 받습니다. 터미널에는 "User answered Claude's questions: → (답)"으로 표시됩니다.

## 6. 메뉴

메뉴바 아이콘을 누르면:

```
Claude Code   연결됨 ✓        ← 눌러서 켜고 끔
Codex         연결됨 ✓
──────────────
(대기 중인 요청 목록)         ← 카드를 닫았어도 여기서 답할 수 있음
──────────────
시작 안내
카드 시험해 보기
도움말 (README)
──────────────
로그인 시 시작
기록 폴더 열기
종료
```

아이콘 모양: 받은편지함 = 대기 없음 · 받은편지함 + 숫자 = 그 수만큼 대기 · `⚠︎` = Node.js를 못 찾음.

## 7. 승인이 오지 않을 때

카드는 **CLI가 원래 물어볼 상황**에서만 옵니다.

- Claude Code가 `auto` 모드면 CLI 자체가 묻지 않으니 카드도 없습니다. 터미널에서 `shift+tab`으로 모드를 바꾸거나 `claude --permission-mode default`로 띄우세요.
- `permissions.allow`에 있는 명령(예: `git`, `npm`을 이미 허용해 둔 경우)도 원래 묻지 않으니 오지 않습니다.
- 앱이 꺼져 있으면 아무것도 바뀌지 않습니다. CLI가 원래 프롬프트를 띄웁니다.

## 8. 끄기·지우기

- 잠깐 끄기: 메뉴 → **종료**. 훅은 남아 있지만 앱이 없으면 CLI가 원래대로 묻습니다.
- 연결 끊기: 메뉴에서 **Claude Code 연결됨** / **Codex 연결됨**을 눌러 끕니다. 설정 파일에서 우리 줄만 빠집니다.
- 완전히 지우기: 연결을 끈 뒤 앱을 지우고, 기록 폴더 `~/.approve-here`를 지웁니다.

## 9. 문제가 있을 때

메뉴 → **기록 폴더 열기**. `app.log`(앱), `daemon.log`(대기함), `requests.jsonl`(모든 요청과 결정)이 있습니다. 증상별 확인 순서는 [README의 "안 될 때"](../README.md#안-될-때)에 있습니다.

## Node.js가 필요합니다

카드 뒤에서 일하는 훅은 Node.js로 돕니다(앱 안에 들어 있고, Node만 시스템에 있으면 됩니다). Claude Code나 Codex를 npm으로 설치했다면 이미 있습니다. 없으면 시작 안내가 내려받기 링크를 보여 줍니다.
