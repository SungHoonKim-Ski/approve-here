# Approve Here

Claude Code와 Codex가 "허용할까요?"라고 물을 때, 터미널 창을 찾아다니지 않고 화면 오른쪽 위 카드 한 장으로 답하는 macOS 메뉴바 앱입니다.

![승인 카드와 질문 카드](docs/cards.png)

## 이런 불편을 풉니다

코딩 에이전트는 파일을 고치거나 명령을 실행하기 전에 멈춰서 허락을 구합니다. 세션을 하나만 띄우면 괜찮습니다. 서너 개를 띄우면 달라집니다.

- 어느 창이 기다리는지 모릅니다. 창을 돌며 찾습니다.
- 못 보고 지나치면 그 작업은 그냥 멈춰 있습니다.
- 같은 종류의 허락을 매번 또 누릅니다.
- 에이전트가 선택지를 주며 물을 때도 그 창으로 가야 합니다.

Approve Here를 켜 두면 어느 세션이 묻든 화면 오른쪽 위에 카드가 뜹니다. 카드에는 어느 프로젝트의 어떤 세션인지, 그 세션에 무슨 일을 시켰는지, 지금 무엇을 하려는지가 적혀 있습니다. 보던 창에서 그대로 허용하거나 거부합니다. 같은 명령은 "앞으로 자동"으로 기억시킵니다. 에이전트의 질문도 카드에 뜨고, 왜 묻는지 설명을 보고 고르면 답이 전달됩니다.

카드를 놓쳐도 됩니다. 에이전트의 원래 화면은 그대로 살아 있고, 먼저 답한 쪽이 이깁니다. 앱을 꺼 두면 아무것도 바뀌지 않습니다.

## 시작하기

1. [최신 릴리스](https://github.com/SungHoonKim-Ski/approve-here/releases/latest)에서 **ApproveHere.dmg**를 내려받아 열고, 앱을 Applications로 끌어 넣습니다. 창 안에 순서가 그려져 있습니다.
2. Applications에서 앱을 엽니다. Apple 서명이 없어 처음 한 번은 macOS가 막습니다. **완료**를 누르고 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 **그래도 열기**를 누릅니다. dmg 안의 **설치 안내**를 열면 그 화면으로 바로 가는 버튼과 화면 사진이 있습니다.
3. 시작 안내가 뜹니다. Node.js가 없다고 나오면 안내의 버튼으로 설치한 뒤 **다시 찾기**를 누릅니다. Claude Code나 Codex를 이미 쓰고 있다면 대개 있습니다.
4. 시작 안내에서 쓰는 에이전트의 **연결**을 누릅니다. 앱이 그 에이전트의 설정 파일에 훅 한 줄을 넣습니다. Codex는 다음 실행 때 새 훅을 신뢰할지 묻습니다.

끝입니다. 에이전트가 실제로 허락을 구하거나 질문하면 카드가 뜹니다. 화면과 함께 보는 안내는 [사용 가이드](docs/GUIDE.md)에 있습니다.

## 카드에서 하는 일

**승인 카드**에는 실행하려는 명령과 에이전트가 붙인 설명이 있고, 버튼은 셋입니다. 허용, 거부, 그리고 "허용 + 앞으로 자동". 마지막 것을 누르면 같은 명령 접두는 다시 묻지 않습니다. 기억시킨 규칙은 메뉴의 **자동 승인 관리…**에서 하나씩 풀 수 있습니다. `rm`이나 `sudo`처럼 되돌릴 수 없는 명령에는 이 버튼이 나오지 않습니다.

**질문 카드**에는 질문 직전에 에이전트가 한 설명이 위에 뜨고, 선택지가 설명과 함께 나옵니다. 하나를 고르면 바로 답이 갑니다. 선택지에 없는 답은 입력칸에 적습니다. 질문이 여럿이면 하나씩 차례로 묻고 마지막에 **답 보내기**를 누릅니다. 질문 카드가 뜨면 소리가 납니다.

카드를 닫아도 요청은 메뉴에 남습니다. 질문 카드의 ✕는 답하지 않고 에이전트의 원래 화면으로 넘깁니다. 메뉴바 아이콘 옆 숫자가 기다리는 요청 수입니다. 노트북처럼 메뉴바가 좁아 아이콘이 숨겨지면 **⌥⇧A**로 같은 메뉴를 부릅니다.

## 무엇이 카드로 오나

| | 승인 | 질문 |
|---|---|---|
| Claude Code | 원래 허락을 구하던 명령·파일 변경 | `AskUserQuestion` |
| Codex CLI | 원래 허락을 구하던 명령·파일 변경 | Plan 모드(`/plan`)에서 묻는 질문 |
| Codex 데스크톱 앱 | 실험적 ([아래](#codex-앱-연결)) | 원래 앱 화면에서 답합니다 |

원래 묻지 않던 것은 여기로도 오지 않습니다. Claude Code를 자동 허용 모드로 쓰거나 허용 목록에 넣어 둔 명령, Codex의 "나 대신 승인" 모드가 처리한 요청이 그렇습니다.

원래 화면과 카드 사이의 관계는 이렇습니다. Claude Code 승인은 터미널 프롬프트와 카드가 함께 뜹니다. Claude Code 질문은 카드가 먼저 뜨고, 20초 안에 답하지 않으면 터미널에 원래 다이얼로그가 뜹니다. tmux 안에서 띄운 세션이면 질문 다이얼로그도 처음부터 함께 뜨고, 카드에서 고르면 앱이 그 다이얼로그에 대신 입력합니다. Codex CLI는 자기 로컬 서버에 앱이 직접 붙어서 카드와 원래 화면에 함께 뜹니다. tmux는 없어도 됩니다.

## 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 앱이 안 열린다 | 정상입니다. **완료** → 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 **그래도 열기**. 이 버튼은 한 번 막힌 뒤 약 1시간 동안 보입니다. 우클릭 → 열기는 macOS 15부터 통하지 않습니다. [화면별 안내](docs/GUIDE.md#2-처음-열기) |
| 메뉴바 아이콘이 `⚠︎` | Node.js가 없습니다. [Node.js 20 이상](https://nodejs.org/)을 설치한 뒤 메뉴에서 **다시 찾기** |
| 카드가 안 뜬다 | 메뉴에서 연결 상태를 봅니다. 에이전트가 원래 묻지 않는 작업은 카드도 없습니다. Codex는 훅 신뢰가 끝났는지 봅니다 |
| Codex CLI 질문 카드가 안 뜬다 | `/plan`으로 Plan 모드를 켠 질문만 옵니다. [연결 조건](docs/CODEX.md#연결-조건과-확인) |
| 메뉴바 아이콘이 안 보인다 | **⌥⇧A**를 누릅니다. 카드는 아이콘과 상관없이 뜹니다 |
| "이미 실행 중"이라고 나온다 | 기존 앱의 메뉴에서 **종료**를 누른 뒤 새 앱을 엽니다 |

더 보려면 메뉴 → **기록 폴더 열기**에서 `app.log`(앱), `daemon.log`(대기함), `requests.jsonl`(모든 요청과 결정)을 봅니다.

## 어떻게 돌아가나

에이전트가 허락을 구하는 순간 훅이 불리고, 훅은 그 요청을 앱 안의 작은 대기함에 넣습니다. 카드는 대기함을 보여 주는 창일 뿐입니다. 대기함은 이 Mac 안(127.0.0.1)에서만 돌고 계정도 서버도 없습니다.

앱은 스스로 허용 여부를 판단하지 않습니다. "앞으로 자동"으로 기억시킨 규칙만 적용합니다. 이미 쓰는 승인 정책 훅이 있으면 `~/.approve-here/config.json`에 적어 앞에 세울 수 있고, 그 훅이 결정하지 못한 것만 카드로 옵니다.

```json
{ "policyHooks": { "claude": ["node /path/to/my-permission-policy.mjs"], "codex": [] } }
```

훅은 어떤 실패에서도 결정 없이 물러납니다. 앱이 꺼져 있어도, Node가 없어도, 훅이 죽어도 에이전트는 원래 화면을 띄웁니다. 기억시킨 규칙은 `~/.approve-here/allowlist.json`, 처리 이력은 `~/.approve-here/requests.jsonl`에 있습니다.

## Codex 앱 연결

실험적 기능입니다. Codex 데스크톱 앱은 자기 안의 Codex와 표준 입출력으로만 통신해서 밖에서 붙을 수 없고, 앱이 읽는 `CODEX_CLI_PATH`로 중계 실행 파일을 지정한 별도 실행기로 열어야 합니다. 시험하려면 시작 안내에서 **Codex 앱 실행기 설치 (실험적)**를 누르고, Codex 앱을 완전히 종료한 뒤 `~/Applications/Codex with Approve Here.app`으로 엽니다. 평소에는 원래 앱을 쓰세요. 앱에서의 승인·질문 응답은 아직 끝까지 검증하지 못했습니다. 이유와 한계, 되돌리는 법은 [Codex 연결 문서](docs/CODEX.md)에 있습니다.

## 개발

```bash
git clone https://github.com/SungHoonKim-Ski/approve-here && cd approve-here
npm ci
npm test
sh surfaces/macos/build.sh     # SwiftPM만으로 .app·zip·dmg. Xcode는 필요 없습니다
```

앱과 zip만 만들려면 `APPROVE_HERE_SKIP_DMG=1`을 앞에 붙입니다. dmg 창 배치는 Finder 자동화 권한을 씁니다. Apple Silicon Mac, macOS 13 이상, Node.js 20 이상에서 동작하고 Windows·Linux·Intel Mac 빌드는 없습니다. MIT 라이선스.
